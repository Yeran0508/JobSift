# Experiment Evidence Rules

Every performance or quality claim must have a reproducible report in this directory.

Each report must identify:

- Git commit and dataset version;
- public source or synthetic fixture provenance;
- hardware and software environment;
- parameters, warm-up, repetitions, and changed variable;
- baseline and raw machine-readable results;
- aggregated metrics, limitations, and conclusion.

Targets are not results. README and resume claims may use a number only after the supporting report exists.
